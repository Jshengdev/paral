The API: creating a short link

One request makes one short link. It goes through six steps, in this order.

Request pipeline

  1. Authenticate. The key is looked up, and with no valid key the request stops here.
  2. Rate limit. Each key may make ten requests a minute.
  3. Parse the body. It must be JSON with a url field.
  4. Validate the address. Only http and https, at most 2,048 characters.
  5. Allocate a code. Six characters, tried again if the code is taken.
  6. Respond. The short address is returned with status 201.

When a step fails

  • A missing or wrong key gets 401.
  • Too many requests gets 429, with the seconds to wait.
  • A body that is not JSON, or an address that is not allowed, gets 400.
