Plan for the link shortener

Spec files, plus a few small extras where two places share logic.

File layout

lib/db.ts          one shared connection, plus migrationslib/codes.ts       six-character codes, retry up to five times on a collisionlib/urls.ts        http and https only, reject our own hostlib/links.ts       createLink(userId, url): validate, then insertlib/stats.ts       total clicks, the last 14 days, top referrerslib/auth.ts        password hash and verify, signed session cookielib/rateLimit.ts   token bucket per key, kept in a Map in memorylib/api.ts         one error shape for every API route

Key decisions

  • Database: tables match the spec, and migrations run on the first load.
  • Redirect: the short link answers with status 307 and records the click after the response.
  • Country: read from the first header present, else "unknown".
